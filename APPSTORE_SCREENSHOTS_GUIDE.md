## Screenshot Technical Specifications

### Image Requirements
- **Format:** PNG or JPEG
- **Color Space:** sRGB
- **Resolution:**
  - iPhone 5.5": 1242 x 2208 px
  - iPhone 6.1": 1170 x 2532 px
  - iPhone 6.5": 1242 x 2688 px
  - iPhone 6.7": 1284 x 2778 px
  - iPad 11": 2048 x 2732 px
  - iPad 12.9": 2048 x 2732 px
- **File Size:** Under 5 MB per image
- **Quality:** No compression artifacts, sharp text

### Device Frame Specifications
✅ **Apple Frames Required:**
- Use Xcode Screenshot Tools or Apple's Device Frame Generator
- Frame should show actual device (iPhone or iPad, not mixed)
- Include status bar (signal, battery, time: 9:41)
- No App Store labels or badges

### Localization
- All screenshots show English text
- Screenshots are identical across all supported languages
- No region-specific content

## Content Guidelines

### What TO Include
✅ Core app features in action  
✅ Navigation and UI elements  
✅ Real content (devotions, verses, events)  
✅ User interactions (search results, forms, lists)  
✅ Responsive design on different devices  
✅ Accessibility features (clear text, good contrast)  

### What NOT to Include
❌ Splash screens or load screens  
❌ Login screens (app doesn't require login)  
❌ Device frames showing wrong device type  
❌ Non-iOS UI elements  
❌ Marketing copy overlaid on screenshots  
❌ AR/VR features (not supported)  
❌ External websites or third-party apps  
❌ Placeholder or dummy content  
❌ Debug or test UI elements

## Upload Instructions for App Store Connect

1. **Log into App Store Connect**
   - Navigate to "New Life Community Church" app
   - Select "Previews and Screenshots"

2. **For Each Device Size**
   - Click "Edit Screenshots"
   - Click "View All Sizes in Media Manager" (important for iPad sizes)
   - Upload all 8 screenshots in correct order
   - Add descriptive captions (see above)

3. **Device Order**
   - iPhone 5.5" (Plus)
   - iPhone 6.1" (Standard)
   - iPhone 6.5" (Max)
   - iPhone 6.7" (Pro Max)
   - iPad 11"
   - iPad 12.9"

4. **Verification**
   - Preview each screenshot on device simulator
   - Confirm text is readable
   - Check for any artifacts or quality issues
   - Save and submit for review

---

## Apple's Screenshot Review Criteria

Apple will review screenshots for:
- ✅ Accuracy: Screenshots match app functionality
- ✅ Device appropriateness: Correct device frames
- ✅ Clarity: Text is readable, UI is clear
- ✅ Completeness: Shows app's main features
- ✅ No marketing: Screenshots show app use, not promotions
- ✅ Platform: iOS UI only, no cross-platform confusion
